# Gemelo Digital · Autopista Sur

Sitio estático para compartir los resultados históricos y las predicciones ya calculadas de 215 segmentos del corredor Bogotá–Soacha. Incluye indicadores, mapa, filtros y circulación ilustrativa.

## Activar GitHub Pages

En Settings → Pages, elegir Deploy from a branch, rama **main**, carpeta **/ (root)** y pulsar Save. GitHub mostrará el enlace cuando termine la publicación.

La publicación contiene una copia fija de los resultados del estudio. No consulta tráfico en tiempo real ni ejecuta CatBoost. Los datos publicados son descargables por los visitantes. Los Parquet originales y la configuración privada del servidor no forman parte de este repositorio.
